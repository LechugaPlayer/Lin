## Software Rasterizer Lin
-Lin is a simple project aiming to offer a fully featured software rasterizer.

Lin only receives 2D coordinates, it does not perform any transformation nor projection it does not perform any
allocationson it's side and has no dependencies with any other library. This is a deliberate design choise,
becausea rasterizer is only concerned with a buffer, and locations to draw, by giving that information to Lin,
it will perform it's task flawlessly.
